## 附录 · 测量方法（可复现）

所有色值、列宽、行结构均由 `PIL` 逐像素采样得出，**没有目测取色**：

- **色板**：对每一行 `y`，在「课目（空域）」列的 x∈[500,940] 上取**众数颜色**，
  再把纵向连续同色段合并成行带 → 得到 banner / 表头 / 五个类别的底纹取值。
- **底纹范围**：对同一行分别取「整行众数」与「第 4 列众数」——整行为 `#FFFFFF`
  而第 4 列为类别色，据此判定**只有课目列着色**。
- **列宽**：在周二区块（y∈[160,400]）上统计每一列 x 的暗像素占比 > 55% 的竖线位置，
  剔除文字笔画后得边界 `8 / 167 / 326 / 486 / 950 / 1109`。
- **A 类字色**：取该行 x∈[500,940] 中 `sum(rgb) < 420` 的最暗像素簇 = `#89372C`，
  结合底纹 `#FFF2CD` 反推，判为标准红 `#C00000`。
- **时长核算**（第 4 节）：`着陆 − 起飞` 与 v6 §1.3.3 的时长列逐条比对；
  机型资质用 v6 §1.3.2「适配课目」列比对；空域容量用 §1.3.4 比对。
